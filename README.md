# CardForge v8.7 — Simple Selling Landing

Главная идея версии: максимально простой сайт с одним понятным обещанием — **одно фото товара → готовая красивая продающая карточка**.

## Frontend

- один крупный before/after на первом экране;
- всего два дополнительных before/after-примера ниже;
- никаких сеток из 36 изображений;
- категории и стили в генераторе — компактные текстовые кнопки;
- дополнительные поля спрятаны в раскрывающийся блок;
- сохранены вход, кредиты, генерация, скачивание результата и повторная генерация;
- адаптивная мобильная версия.

## Backend

Backend взят из v8.6.2 без функциональных изменений. Prompt уже сохраняет товар и меняет только его подачу.

## Обновление

Для GitHub Pages замените содержимое frontend содержимым `frontend-github/`.
На VPS не заменяйте рабочие `.env` и `data/`.
