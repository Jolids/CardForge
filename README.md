# CardForge frontend v8.1

Новый интерфейс в коде:

- категория → визуальные концепции;
- реальные превью товаров вместо абстрактных градиентов;
- одна и та же кружка показывает разные сценарии категории «Дом»;
- «Свой стиль» остаётся отдельным свободным режимом;
- мобильный горизонтальный скролл категорий и концепций;
- сохранена авторизация, бесплатная генерация, баланс и Lava.top.
