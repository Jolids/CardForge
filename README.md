# CardForge frontend v7 — marketing redesign

Эта версия меняет только публичный frontend. Backend v6.2 менять не нужно.

## Что нового

- сильный первый экран: «Соберите карточку для маркетплейсов»;
- понятный оффер для продавцов;
- 4 ключевых преимущества сразу под hero;
- крупные качественные примеры;
- блок «как это работает»;
- before/after презентация;
- сохранён рабочий генератор v6.2 с категориями и готовыми сценами;
- публичный блок тарифов загружается прямо из `/api/billing/packages`;
- сохранены локальная авторизация, баланс и Lava.top;
- адаптивное мобильное меню и мобильная верстка.

## Публикация

Замените содержимое корня GitHub Pages репозитория файлами из этой папки:

- `index.html`
- `styles.css`
- `app.js`
- `config.js`
- `.nojekyll`
- `assets/`

Backend на VPS перезапускать не требуется.

После коммита откройте:

`https://jolids.github.io/CardForge/?v=70`

Если GitHub Pages показывает старый дизайн — обновите страницу без кэша.
