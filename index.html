FAQ

Частые вопросы

CardForge меняет сам товар?

Нет. Сервис старается сохранить форму, пропорции, цвет, материал, логотип и видимые детали товара. Меняется подача: фон, свет, окружение и композиция.

Нужно писать промпт?

Нет. Достаточно выбрать стиль. Пожелания можно добавить только если хочется точнее направить результат.

Можно добавить текст прямо на карточку?

Да. Укажите заголовок и реальные преимущества товара — CardForge встроит их в дизайн и не будет придумывать характеристики за вас.

Подойдёт фото с телефона?

Да. Лучше всего работает чёткая фотография, где товар хорошо виден и не перекрыт другими предметами.

Правила сервиса и данные

Пользовательское соглашение

1. Сервис. CardForge предоставляет инструменты для AI-обработки фотографий товаров и создания рекламных материалов. Пользователь самостоятельно выбирает исходные изображения, тексты и параметры генерации.

2. Аккаунт. Для генераций используется аккаунт с email и паролем. Пользователь отвечает за сохранность своих данных доступа и действия в своей сессии.

3. Контент. Пользователь подтверждает, что имеет право загружать используемые изображения, логотипы, тексты и иные материалы. Запрещено использовать сервис для незаконного контента или нарушения прав третьих лиц.

4. Результат AI. Генеративные модели могут допускать неточности. Перед публикацией пользователь обязан проверить изображение, текст, характеристики товара, товарные знаки и иные сведения. CardForge не гарантирует идентичность каждого результата ожиданиям пользователя.

5. Кредиты и оплата. Один кредит используется за одну успешно завершённую генерацию. При подтверждённой технической ошибке генерации кредит не должен списываться. Оплата пакетов проводится внешним платёжным провайдером Lava.top. Автоматической подписки нет.

6. Возвраты. Вопросы ошибочных или спорных списаний рассматриваются индивидуально с учётом факта оказания услуги, правил платёжного провайдера и применимого законодательства. Для обращения используйте форму обратной связи.

7. Доступность. Сервис может временно быть недоступен из-за технических работ, ограничений AI-провайдеров или внешней инфраструктуры.

8. Изменения. Условия могут обновляться вместе с развитием сервиса. Актуальная редакция публикуется на сайте.

9. Связь. Вопросы по сервису, оплате и данным можно направить через форму «Обратная связь» на сайте.

Политика конфиденциальности

Какие данные хранятся. Email аккаунта, технические данные сессий в хешированном виде, история генераций, баланс кредитов, сведения о платежах, события использования и сообщения обратной связи.

Для чего. Эти данные используются для авторизации, работы генераций, начисления кредитов, поддержки пользователей, предотвращения злоупотреблений и внутренней аналитики сервиса.

Изображения. Загруженные изображения передаются выбранному AI-провайдеру для выполнения генерации. CardForge не сохраняет исходные фотографии в аналитическую базу. Временный результат может храниться в серверном кэше ограниченное время для безопасного повторного получения после сетевого сбоя.

Оплата. Платёжные реквизиты вводятся на стороне Lava.top. CardForge хранит только служебные данные платежа: пакет, сумму, статус, идентификатор и email.

Обратная связь. Сообщение, тема и указанный email сохраняются в базе CardForge, чтобы администратор мог рассмотреть обращение.

Передача данных. Данные не предназначены для продажи рекламодателям. Необходимая информация может передаваться поставщикам инфраструктуры, AI и платежей исключительно для работы соответствующей функции.

Связь по данным. Для вопросов об обработке данных используйте форму обратной связи.

Этот текст описывает правила работы CardForge и не заменяет индивидуальную юридическую консультацию для конкретной юрисдикции.
